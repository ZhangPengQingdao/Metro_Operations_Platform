# 本地向量模型试跑（1.7.1）

2026-10-27，用户授权下载小型本地模型，并明确后续部署也需要支持服务器本机及内网模型。

## 模型与运行环境

- 官方模型：[BAAI/bge-small-zh-v1.5](https://huggingface.co/BAAI/bge-small-zh-v1.5)，MIT，约24M参数，512维，最长512 tokens。
- 固定模型修订：`7999e1d3359715c523056ef9478215996d62a620`。只下载 safetensors 权重及必要配置、分词文件，不执行模型远程代码。
- 下载文件总计96,405,251字节（约96.4MB）；独立Python环境磁盘约721MiB。运行在当前Apple Silicon机器的CPU上，4线程。
- 模型与运行文件位于忽略目录 `output/local-embedding/`，不进入应用包或提交。服务监听 `127.0.0.1:3212`，实际请求 `/v1/embeddings`，使用随机本地密钥；加载后使用本地文件离线推理。
- 平台独立环境为前端3210、API3211、PostgreSQL5566，已配置512维和最低相似度0.55。其他运行实例未变更。

## 平台接入

实际管理端接口 `/embedding/test` 返回512维，`/embedding/save` 保存成功且没有回传明文密钥。两条慧策通标准示例由后台任务生成真实向量，列表状态为「已就绪」。工具实际调用返回 `retrieval.mode=semantic`，带条目ID和版本；无关火锅问题未返回标准示例。

浏览器实际测试向量连接、留空密钥保存配置成功，维度512与阈值0.55正确回显。实际点击「重建索引」后，条目从待索引恢复到已就绪，正文版本不改变。截图位于 `output/playwright/p3-local-model-ready.png`。

部署不限制公网HTTPS：新增运维启动环境 `MOP_EMBEDDING_ALLOWED_ENDPOINTS`，精确列出本机/内网HTTP或HTTPS完整请求地址。未批准的地址继续公网HTTPS检查，全部请求禁止重定向，聊天模型策略保持独立。配置示例见 [部署说明](deployment.md)。

## 小样本检索

独立评估构造6条运维示例（自动售检票巡检、屏蔽门检修、消防演练、新员工培训、备件盘点、卫生保洁），按平台同样的标题/正文/metadata JSON输入编码，用6条不同措辞的业务问题和2条无关问题检索。

| 问题 | 首条命中 | 相似度 |
| --- | --- | --- |
| 乘客刷卡进不去，查一下检票闸机 | 自动售检票巡检 | 0.7328 |
| 列车旁的自动隔离门打不开，要修好 | 屏蔽门检修 | 0.6222 |
| 着火了大家怎么撤离，安排一次练习 | 消防演练 | 0.6936 |
| 新来的同事上岗前学习操作规范 | 新员工培训 | 0.6669 |
| 仓库里维修用的零件还够吗 | 备件盘点 | 0.6374 |
| 把站厅地面和通道打扫一下 | 卫生保洁 | 0.6590 |

6/6业务问题首条命中预期。火锅和股票问题最高分为0.3770和0.3239，原0.3门槛存在误匹配。新增管理端最低相似度配置（0–1，旧配置默认0.3），本次设0.55后两组无关问题均无匹配；调整门槛不重建向量。

最后一次CPU热运行的14次请求平均6.3ms、最大23.3ms（含本机HTTP往返，不含启动加载）。这是自建小样本与单机串行测试，不代表真实语料准确率、生产吞吐或延迟保证。部分业务查询仍有第二、第三条较弱匹配；阈值需要用实际语料进一步调节。未使用query前缀或reranker。

## 检查与限制

- 相关知识库、配置、架构检查24/24通过；补充地址白名单环境校验后向量测试7/7通过，包含阈值过滤、保存阈值不重建、不同端口/路径不放行、聊天策略隔离、URL凭据/查询/片段拒绝。
- SDK、CLI、前后端构建与前端类型检查通过；版本一致性及差异空白检查通过。平台版本1.7.1，慧策通保持2.4.0。
- 本地服务错误密钥返回401；超过512 tokens返回400，不静默截断。平台把供应商失败显示为索引失败；手动修复后重建。
- 本次向量试跑时尚未配置聊天生成模型；2026-10-28已补充[DeepSeek真实对话验收](acceptance-deepseek.md)，验证计划生成及语义检索引用。
- 当前Python HTTP服务是本机试跑脚本。正式服务器应将选定兼容模型服务纳入运维进程管理，平台无需绑定具体推理框架。

## 本地操作

以下命令从仓库根目录执行，各长驻服务使用独立终端；已运行时不要重复启动：

```sh
output/local-embedding/.venv/bin/python output/local-embedding/serve.py
server/node_modules/.bin/tsx output/agent-integration-1.6.0/platform.ts
```

健康检查：`curl http://127.0.0.1:3212/health`。在对应终端按Ctrl+C停止。模型与凭据保留在忽略目录；密钥不要复制到文档、命令参数或聊天。

复测小样本：`output/local-embedding/.venv/bin/python output/local-embedding/evaluate.py`。实际平台复测：`node output/local-embedding/platform-check.mjs`。

证据：`output/local-embedding/model-info.json`、`requirements.lock`、`evaluation.json`、`platform-result.json`。本轮未提交、推送或部署生产。
