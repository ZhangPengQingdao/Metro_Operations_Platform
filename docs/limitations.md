# 当前能力边界

- 平台提供管理端、员工端、组织/人员/车站/设备目录、授权与审计、模型配置、`.mopkg` 应用的安装升级与运行，以及 SDK/CLI 与共享组件。
- 应用后端以平台子进程运行（同一主机、同一系统用户），没有容器级隔离；面向内部、经管理员审核的应用。不适合运行不受信任的第三方代码。
- 应用数据只能通过声明式迁移建表、加可空列、建索引，不支持任意 SQL、重命名列或带默认值的非空列。
- 页面可直接调用的只有只读目录操作；写操作、签字、通知、AI、Webhook 必须经应用接口。
- 跨应用互相调用、应用订阅平台事件、无人登录的后台调用（定时任务以应用服务身份运行，不代表员工）、外部系统集成尚未开放。
- 没有应用卸载；可以停用。
- 写入外部系统（Webhook 等）结果未知时不会自动重试，由应用和使用者核对。
- 不带入旧系统的数据、账号或历史应用包。
- 员工个人资料使用原人员表与默认租户的企业微信外部身份记录。自行填写或更改 UserID 不获得已核验身份；修改后清除核验状态。手机号自助维护暂不包含短信核验。
- 登录限流为单进程；横向部署需另接共享限流。
