# 当前能力边界

0.0.1 是独立项目的起点，不表示所有业务应用或生产运行能力已经完成。

- 已保留管理端、基础数据、独立管理员、模型配置、授权审计、签名安装升级、运行状态和恢复，以及 SDK/共享组件。
- 默认可安装无后端沙箱应用和有健康端点的隔离 Node 后端应用。
- managed storage、业务 API、工具、任务、事件、外联和 trusted UI 的基础实现与测试已保留，但默认管理端装配尚未接通，声明这些能力的包会在安装前拒绝。
- 生产 HTTPS 应用资源域未接入；普通员工的实际业务应用入口与授权接线需要随首个真实应用完成。
- 外部执行结果未知时保留记录并阻断，不能自动重试或制造恢复证据。
- 不带入旧系统的数据、账号、故障、隐患、待办或历史应用包。
