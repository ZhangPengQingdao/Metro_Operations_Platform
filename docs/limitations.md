# 当前能力边界

0.0.1 是独立项目的起点，不表示所有业务应用或生产运行能力已经完成。

- 已保留管理端、基础数据、独立管理员、模型配置、授权审计、签名安装升级、运行状态和恢复，以及 SDK/共享组件。
- 默认可安装无后端沙箱应用和有健康端点的隔离 Node 后端应用。
- managed storage 生命周期已支持显式装配，但默认关闭；需要独立高权限管理连接、数据库 ACL 前置检查及隔离后端配置。已接通服务身份的 UUID 单行读写；新增迁移的结构升级、未知日常写入证据核对入口尚未接通，详见 [托管存储](managed-storage.md)。
- 默认 Gateway 已接通按 ID 读取位置、设备；员工权限与应用委托授权取交集，服务授权单独检查。目录列表、业务写操作仍待实现。
- 应用自定义 API、工具、任务、事件、外联和 trusted UI 的默认管理端装配仍未接通，声明这些能力的包会在安装前拒绝。
- 生产 HTTPS 应用资源域未接入；普通员工已提供独立账号、会话和 Gateway 后端入口；员工登录页面、应用列表与沙箱身份桥仍待实现，尚无真实业务应用闭环。
- 外部执行结果未知时保留记录并阻断，不能自动重试或制造恢复证据。
- 不带入旧系统的数据、账号、故障、隐患、待办或历史应用包。

- 0.2.0 提供 Ubuntu 24.04 amd64 平台安装和在线更新实现；发行签名配置和正式不可变 Release 已完成，见 [发行记录](release-0.2.0.md)。目标机 HTTPS/systemd 与恢复演练仍需实际验收。安装器默认不开放应用托管，宿主更新器协议升级仍需人工处理。
