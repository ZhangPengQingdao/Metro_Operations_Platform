# 当前能力边界

0.0.1 是独立项目的起点，不表示所有业务应用或生产运行能力已经完成。

- 已保留管理端、基础数据、独立管理员、模型配置、授权审计、签名安装升级、运行状态和恢复，以及 SDK/共享组件。
- 默认可安装无后端沙箱应用和有健康端点的隔离 Node 后端应用。
- managed storage 生命周期已支持显式装配，但默认关闭；需要独立高权限管理连接、数据库 ACL 前置检查及隔离后端配置。已接通服务身份的 UUID 单行读写、游标分页及带旧值校验的原子多行写；已支持追加迁移升级与管理员迁移证据核对；日常写入原事务证据核对已接通（无证据的历史记录仍阻断），详见 [托管存储](managed-storage.md)。
- 默认 Gateway 已接通按 ID 读取位置、设备和位置有界分页搜索、在职工班成员的有界搜索；员工权限与应用委托授权取交集，服务授权单独检查。设备及其他目录列表、业务写操作仍待实现。
- 隔离 Node 应用可声明自定义 API，但必须配置 Docker，并逐接口使用本应用定义的权限；工具、任务、事件、外联和 trusted UI 仍在安装前拒绝。
- 0.4.0 已接通独立 HTTPS 资源域，使用 60 秒一次性地址和访问时授权复核，真实域名/TLS 仍需目标机验收；普通员工已有独立账号管理、登录、应用列表和沙箱身份桥；应用须显式分配员工使用授权。管理端可配置员工角色与本应用权限；自定义 API 当前只接受完整操作权限，业务数据范围由应用使用可信员工组织进行约束，不能把组织/本人范围自动降级成全部。物料应用已有签名试装包，本地 Docker 已完成安装、业务权限和保留数据升级验收，目标 Linux 服务器仍需试装。
- 外部执行结果未知时保留记录并阻断，不能自动重试或制造恢复证据。
- 不带入旧系统的数据、账号、故障、隐患、待办或历史应用包。

- 0.2.0 提供 Ubuntu 24.04 amd64 平台安装和在线更新实现；发行签名配置和正式不可变 Release 已完成，见 [发行记录](release-0.2.0.md)。目标机 HTTPS/systemd 与恢复演练仍需实际验收。0.4.0 安装器可显式开启应用试装托管，仍依赖专用实例高权限存储连接及宿主 Docker socket，宿主更新器协议升级仍需人工处理。

- 员工个人资料使用原人员表与默认租户的企业微信外部身份记录。自行填写或更改 UserID 不获得已核验身份；修改后清除核验状态，不能作为企业微信认证依据。其他租户的身份绑定仍由管理流程维护。手机号自助维护暂不包含短信核验。
