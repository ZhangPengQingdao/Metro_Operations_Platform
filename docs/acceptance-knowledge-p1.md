# 平台知识服务 P1 验收记录

日期：2026-10-27。分支：`codex/unified-agent-platform`。平台1.4.0，慧策通2.1.0。

## 交付

- 应用通过 `app.json.knowledgeBases` 声明知识库、检索方式和读取／维护业务权限，随安装生效。
- 平台提供 `platform.knowledge.list/search/write`，公共 SDK 入口为 `@metro/platform-sdk/app-knowledge`。
- 知识条目按应用安装实例、库与组织隔离。检索和完整列表／维护分别授权，显式支持本人范围读取所属组织祖先的共享语料。
- 精确名词匹配和基础字符相似检索；无相关示例时返回空结果。精确命中超过40条时拒绝而非截断。
- 条目版本检查、删除失效、同名名词约束；写入事务及 requestId 幂等，不自动重试。
- 慧策通语料维护和计划建议改用平台知识服务。页面字段和交互保持原样，应用继续负责计划结构、质量标准和名词保护。
- 开发者中心与离线开发资料新增知识库指南；更新部署说明、公共契约和版本记录。

用户已确认“尚无有效语料，可直接改接平台知识库”。本次没有数据导入、双写或旧表删除，也未改写历史迁移文件。工作区中此前已有的慧策通重构改动保留。

## 自查与限制

新增 Gateway 在入口校验业务参数一次，服务层接收确定类型；宿主处理应用准入，知识接口处理库与组织授权。只在知识接口边界转换领域错误，事务和连接释放复用既有实现。

本次未引入新服务、通用工作流框架、向量数据库、自动重放或兼容双写。知识检索仍是结构化文本的基础匹配，不是语义向量 RAG；统一聊天入口、意图路由、应用编排和 MCP 仍属于 P2，文档解析属于 P3。

未连接真实模型执行端到端生成；生成部分采用固定模型响应验证知识注入与业务校验。未执行浏览器人工验收，本次没有布局改动，主要验证数据／权限链路与原页面调用契约。

未更新实际环境数据库、安装应用包、提交、推送或部署。上线时先按已有流程更新平台并执行 `db:init`，再安装慧策通2.1.0；不能只升级应用。
