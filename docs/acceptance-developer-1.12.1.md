# 开发者中心与 Skill 验收（1.12.1）

## 交付

完整 Skill 包内含同版本 SDK/CLI、SHA-256 清单、建项目脚本与参考文档。模板修正命令为 mop-app，生成项目同时携带参考文档。开发者中心展示统一接口、工具安装与测试指南，文档支持表格、列表、代码及内部链接。

应用接口目录改为展示当前员工可接入的跨应用接口，提供 consumers、调用依赖和示例，并支持搜索与入口筛选。新增 `/api/developer/catalog` 提供说明；原 `/interfaces` 和 `/call` 继续限制个人可执行范围。新增 Bearer 鉴权的 `/api/developer/downloads` 与 `/downloads/:id`，复用已有下载校验。

## 验证

- 平台全量 562 项测试通过。新增测试覆盖仅向应用开放的接口可发现、个人调用拒绝、声明依赖后跨应用调用、撤权与依赖拒绝；工具下载验证有效密钥、撤销、跨 Origin 和旧凭证范围。
- SDK、CLI、开发资料、前后端构建、前端类型检查和版本检查通过。
- 从生成的 Skill 归档解压，在独立临时目录运行 create-app.mjs，无平台源码或平台密钥，生成应用并通过 3 项模板测试、check 和 build，产出 .mopkg。验证已有项目不被覆盖、工具摘要不符时在安装前拒绝，完整包与生成项目的 Skill 链接均可解析。
- Playwright 使用真实页面组件和受控 API 数据，验证指南跳转、接口搜索、应用专用接口不显示个人调试按钮、开放个人接口可执行查询、Skill 下载优先展示；检查 390px 明色及 320px 暗色布局无横向溢出。截图和操作脚本保存在本地忽略目录 output/playwright/developer-1.12.1/。

## 范围

页面数据为受控数据，未访问生产业务或使用真实开发密钥。业务应用执行权限的回归包括既有真实应用子进程测试。此记录不表示已部署生产，当前实例需更新平台才能看到新版开发者中心，已安装业务包仍分别管理。
