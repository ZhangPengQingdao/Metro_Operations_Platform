## 自查与部署边界

输入结构分别在 HTTP、应用 API 和模型返回边界校验；宿主负责应用准入，业务函数负责资源范围。会话回复按纯文本渲染，应用链接来自清单；模型不能指定未声明目标、员工身份或任意 URL。旧权限范围的回复不会进入后续应用上下文，路由等待期间权限变化会终止本轮。

会话表通过现有 db:init 增量迁移。部署前执行迁移，随后更新平台和两个应用包，并使用已配置的真实模型验收自然语言意图路由。真实模型的路由准确率、现场授权与模型延迟尚未联调，不把测试桩结果当作线上验收。
