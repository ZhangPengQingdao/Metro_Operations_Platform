# 独立项目拆分说明

本项目从已有平台实现提取，业务实现留在原 AFC 仓库供参考。新仓库为独立 Git 历史，启动、构建、测试不依赖旧仓库；初始版本 0.0.1。

保留 Core、共享 UI/工具、平台契约、应用宿主、管理端、SDK 和相关测试。移除旧业务路由/页面/任务调度器、旧认证入口、历史部署脚本、迁移进度台账、临时预览、运行产物、上传包和本地密钥。旧仓库不删除、不清理，也不复制其数据库。

历史测试中，仅针对旧入口转接、旧数据库迁移台账和旧业务保留状态的检查不再纳入新仓库；平台行为测试保留。新增独立数据库初始化、无旧业务表、版本同步检查。界面/样式与原平台保持一致，严格类型问题在新仓库修复。

共享图标/Logo 延续原平台已采用的资源（其中侧边栏 SVG 参考 OmegAI）；包名使用 @metro/platform-sdk。应用协议中的稳定字段、权限代码和隔离策略继续保留，避免仅因改名制造第二套协议。

拆分验收：634 项平台测试通过，8 项依赖显式环境的测试跳过；严格前端类型检查、SDK/前后端构建通过。独立本地 PostgreSQL 新建角色和数据库，29 项初始化迁移成功；新入口登录、旧业务路由隔离、签名安装与重复请求、停用拒绝页面、0.0.1 → 0.0.2 更新后明确启用均实测通过。运行数据及验收凭据不进入 Git。
