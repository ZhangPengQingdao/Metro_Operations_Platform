# 检修管理独立应用

检修管理按“计划组 → 设备明细”组织。计划记录日期、工班、车站、设备类型、内容和逐台派工；每台设备记录主/副作业人、占比、待执行/已完成状态和完成时间。计划状态由全部设备的完成状态计算。修改采用 revision 比较，作废为留痕软删除。

页面使用公开 L2 `QueryList`、`SearchSelect`、`DropdownSelect`、`Dialog` 和表格操作按钮，查询与列表样式和晨会交接、故障记录一致。车站与设备候选来自平台目录；导入允许保留手填名称，人员必须来自所选工班目录。检修业务数据存入应用私有托管存储，不读取平台旧业务表。Excel/UTF-8 CSV 文件在员工沙箱内解析并预览，原文件不上传或留存；CSV 以原始文本读取，避免设备编号 `01/02` 被误转为日期。应用只经业务 API 保存核对后的计划。

与旧 AFC Ops Manager 对照：计划组查询、新增编辑、逐台完成、批量导入模板及按月份导出在本应用中提供；旧项目的月计划同步接口、与交接记录自动关联、设备标准化匹配及特殊归档模板依赖旧系统数据或规则，本版未接入。导出采用扁平设备明细工作表；旧数据无自动迁移。后续若需迁移，应先确定字段映射、业务授权和数据核对方式。

验收重点：不同工班和本人权限范围下的查询/修改；完成设备不可删除或退回、整组不可作废；多人占比、导入部分成功与未知写入结果；沙箱内按钮保存、下载及窄屏布局。安装审批可一并批准服务所需平台能力；安装后还需配置应用负责人和员工业务角色，并以真实员工身份核对目录数据。
