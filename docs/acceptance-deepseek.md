# DeepSeek 真实对话验收（平台 1.7.1）

2026-10-28，在独立本地环境验证：前端3210、API3211、PostgreSQL5566、本地向量模型3212。使用专门的联调员工和合成语料，未修改其他实例。

## 模型配置

通过平台管理接口读取供应商模型列表，返回 `deepseek-flash` 和 `deepseek-v4-pro`，本轮选择 `deepseek-flash`。请求地址为 `https://api.deepseek.com/v1/chat/completions`；密钥使用现有平台加密配置保存，不进入源码、验收报告或应用包。

连接测试返回 `tool_calling=true`，耗时1746ms。该测试只验证模型工具调用格式；业务链路的 MCP 调用由应用编排按既定步骤执行，不代表已实现模型自主工具循环。

知识向量继续使用本地 `BAAI/bge-small-zh-v1.5`（512维、最低相似度0.55），与聊天模型分别配置。

## 实际结果

| 场景 | 结果 | 单次耗时 |
| --- | --- | --- |
| 查看我的未完成待办 | 正确分流到待办事项，经 MCP 返回自己的联调待办，不包含其他员工记录 | 3.5秒 |
| 月度计划未提供月份 | 正确分流到慧策通，追问月份 | 2.8秒 |
| 同一会话补充月份、日期和质量标准 | 生成2026-11计划内容，保留“联调AFC”，日期正确，展示语义检索来源ID与版本，标明草稿未提交 | 8.8秒 |
| 同一会话改查已完成待办 | 切换到待办事项，返回实际空结果 | 3.4秒 |
| 请求订机票 | 不调用业务应用，说明未支持并引导可用能力 | 2.8秒 |
| 无应用权限员工查询待办 | 不调用模型或应用，返回没有可用能力 | 14ms |
| 另一员工读取对话 | 返回404 | — |
| 进入慧策通处理阶段后取消 | 状态为cancelled，取消后1.5秒复查没有生成回复 | — |

本轮技术审计包含 `list-todos / mcp` 和 `plan-reference / direct`。前后对比慧策通工作记录数量不变，生成的草稿没有写入业务表。以上耗时包含本地HTTP往返和轮询，不是性能承诺。

浏览器已实际打开上述连续对话，确认计划、来源版本和应用链接展示；再从侧栏「新建对话」点击待办提示卡，提示词仅填入聊天框，点击发送后收到真实待办结果。会话恢复与本轮操作没有新增控制台错误；此前未登录及过期会话产生的401保留在浏览器日志中。

## 效果边界与后续
