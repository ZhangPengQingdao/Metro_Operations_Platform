- 专项使用真实 V2 数据服务和 PGlite 执行当前迁移及业务事务；构建实际应用后端，在 V2 子进程中验证启停钩子、员工调用绑定、原始附件授权回调和无附件拒绝完成。
- SDK／CLI、前端、服务端和应用构建、前端类型检查、应用 check、版本一致性与 diff 空白检查通过。
- 附件专项流式上传 **51 MiB MP4**，超过旧 50 MiB 上限，原件完整下载；单文件硬上限为 200 MiB，并验证超限暂存清理和独占写入碰撞不会删除原文件。
- 单条及嵌套批量 ZIP 经过浏览器下载，再使用 Python zipfile 独立核对 CRC、文件层级和原件字节一致。

## 前阶段页面操作（独立测试宿主）

在本地验收环境使用实际应用页面、新业务服务、真实 V2 数据服务和原件 HTTP 接口；人员、会话、AI 返回及 Webhook 发送使用测试替身，不连接真实群。

1. 自然语言输入 → 整理 → 选择单一责任人 → 提交审核。
2. 审核通过 → 查看执行计划；无附件时完成按钮不可用。
3. 上传 PDF → 责任人确认完成，无第二轮审核 → 单条附件 ZIP 下载。
4. 勾选计划 → 批量导出日期 ZIP；独立解压验证内部计划包及原件。
5. Excel 映射三列 → 解析月份与人员 → 预览 → 导入两条年度计划。
6. 月度提报检查 4 月出现 2—5 月年度事项、6 月不出现；10 月出现 10—12 月事项。
7. 年度列表行内点击完成，不弹出额外审核。
8. 派发督办 → 责任人直接完成，无强制附件条件。
9. 新增专有名词与标准示例；保存关闭状态下的测试 Webhook 配置。
10. 桌面亮暗主题检查；语料库和督办页无额外部门标签、说明段落，描述输入维持幽灵样式。前阶段曾查看窄屏，本轮不将窄屏作为验收标准。

截图及执行日志位于本地忽略目录 `output/playwright/`、`output/huicetong-acceptance/`，不提交运行数据。
