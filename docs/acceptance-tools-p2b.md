# P2b 只读工具与 MCP 验收记录

日期：2026-10-27。平台 / SDK / CLI / API：1.6.0；慧策通：2.3.0；待办事项：1.2.0。

## 交付范围

按用户确认交付只读工具与受管 MCP 接入。应用清单声明工具、输入契约、业务权限及独立 API；SDK 的 `createAppToolClient` 提供目录与调用，支持 direct 和 mcp。两种传输复用同一应用宿主授权与参数入口，不新增应用监听端口。

待办事项编排通过 MCP 查询员工业务范围内待办；慧策通编排通过直调工具检索当前部门名词与示例，再生成计划草稿。统一入口沿用“工作台”下方“新建对话”，卡片仍只填写提示词。

## 验证结果

- 后端全量测试：508 / 508 通过。
- 新增 6 项工具专项测试：清单约束、封闭参数、非法工具与身份覆盖、直调 / MCP 行为一致、普通 API 不能绕过工具校验、业务错误、动态撤权、应用停用、平台授权、实际员工审计、写操作拦截及取消传播。
- 官方 MCP Client 实际执行初始化、工具列表与调用；覆盖未知方法及未知工具、业务失败 `isError` / `structuredContent`。未用自制 JSON 协议代替 MCP。
- 真实受管子进程执行工具 handler，验证从 MCP 经 IPC 到嵌套平台读取的取消；通过写入计数确认只读工具不能使用应用既有的平台写权限。
- 统一对话集成测试实际打包慧策通和待办事项后端，验证编排 → 直调 / MCP → 应用工具 → 知识 / 数据查询。模型与数据返回使用受控测试数据，待办查询保留员工范围过滤。
- 慧策通 39 / 39、待办事项 16 / 16 测试通过；两个应用清单检查及 `.mopkg` 打包通过。
- SDK、CLI、前端生产构建、前端类型检查、后端构建通过；开发者文档清单示例经过实际校验器验证。
- `npm run version:check`、`git diff --check` 通过。数据库迁移在全量测试的临时 PGlite 数据库中执行并验证可重复初始化。

## 自查

首轮全量测试发现工具服务反向依赖应用宿主层，已把执行服务与 MCP 适配放入 `app-platform/tools`，架构检查恢复通过。工具参数只在宿主 API 入口按 schema 校验；网关只验证协议包装，应用处理函数继续负责业务资源范围。

SDK 不允许覆盖员工或应用身份，不自动重试；审计只记录工具名、传输及身份，不记录参数和知识内容。只读拦截位于宿主网关；受信任应用仍运行在原 Node 子进程中，这不构成操作系统沙箱。

本轮没有改变聊天交互或布局，沿用 [P2a 浏览器验收](acceptance-chat-p2a.md)。管理员开发者中心增加工具指南，公开参考和离线文档随构建更新。

## 现场验收与未实施项

现场仍需按[升级说明](deployment.md)更新平台、执行权限定义迁移、安装新应用包并配置服务授权，再用真实模型和员工账号验收：统一入口填写“查看我的未完成待办”；填写带月份的慧策通计划并核对知识命中与草稿；取消请求；以无业务权限账号确认对应能力不可见。

本次未提交、推送、部署、安装应用或迁移实际数据库；未验证现场模型路由准确率和模型响应延迟。第三方远程 MCP、对外 MCP 服务、模型自主工具循环、确认写入与文档向量 RAG 不在本轮交付范围。

用户选择独立本地环境，并明确先验收不依赖模型的功能。环境为 PostgreSQL 17（5566）、平台 API（3211）、浏览器入口 `http://127.0.0.1:3210`，文件位于忽略目录 `output/agent-integration-1.6.0/`。未改动另一工作区的 3100/3101 实例及线上环境。

通过实际平台迁移、管理员登录及安装 API，安装慧策通 2.3.0 与待办事项 1.2.0，两者均 serving，声明的平台服务权限正常授予。隔离库创建测试组织和两个测试员工；业务角色由测试脚本准备，未验证管理端角色配置交互。

已完成的实际联调：

- 员工登录后能力目录返回“整理月度计划”和“查看待办事项”，无权限员工目录为空。
- 通过慧策通业务接口创建测试名词和示例，实际知识检索工具命中 1 个名词与 1 条示例。
- 通过待办业务接口创建测试任务，另准备其他员工的隔离测试记录；只读工具与 `agent-todos` 编排实际经 MCP、应用子进程和 PostgreSQL 返回本人的 1 条任务，未泄露其他员工记录。
- 工具参数插入 personId 返回 400，无权限员工调用返回 403；其他员工读取会话返回 404。
- 实际技术审计包含 MCP 传输、工具及绑定员工身份。
- Playwright 使用真实员工会话和真实后端，验证侧栏位置、卡片仅填入提示词、发送、历史列表、无权限空态；截图人工查看通过。未拦截或模拟接口。
- 未配置模型时，聊天请求正常结束为失败并显示提示；不会生成伪造答案。此结果只验证错误路径，不能视为意图识别或计划生成成功。
