# 开发者中心与跨应用查询 1.11.0 验收

日期：2026-11-02。工作分支：codex/unified-agent-platform。此次验收在本地执行，未部署，未修改生产数据库或真实员工角色。

## 交付

- 员工侧栏新增开发者中心；共用文档、SDK 能力参考和下载页面。管理员身份仍与员工独立。
- 启用公共目录白名单：线路、车站、线路车站关系、组织工班、工班管辖车站、岗位、设备系统/类别/类型。搜索与稳定分页，前端可下载本页 JSON。
- 个人只读凭证：目录与应用查询两类范围，有效期最长 90 天，每人最多 5 个有效 Key。完整值只在创建响应显示，服务端保存摘要；过期/撤销/改密拒绝使用，账号、人员、组织和岗位状态每次核验。
- 声明式开放只读接口、输入输出文档、逐接口跨应用依赖。运行时按目标应用员工权限执行；输入输出校验，升级/角色/范围变化后不释放旧结果。只允许一层调用，开放处理器禁止平台写操作。
- 故障记录 1.1.0 public-query 提供摘要；检修管理 1.1.0 计划详情按车站调用此接口，源计划与目标故障分别鉴权。
- SDK、离线开发指南与 Agent Skill 同步。平台版本统一为 1.11.0。

## 自查与上线要求

自查覆盖权限交集、服务端身份来源、字段白名单、分页、凭证存储与失效、审计事务、只读执行边界和错误反馈。未引入另一套角色、审批、服务账号、分布式事务或跨应用写入。

正常在线更新执行 developer-access-expand；手动源码部署先运行 db:init。两业务应用需分别安装 1.1.0，并确认相关员工在两应用中的业务角色。建议验收同工班可读、跨工班拒绝、目标应用撤权以及凭证撤销。跨应用纯查询仍要求应用开发者不自行执行外部副作用，平台只读保护覆盖平台网关写操作。
