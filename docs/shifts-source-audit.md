# 晨会交接：原功能对照与返工清单

更新：2026-09-20。当前是开发中的实现，不是已完成交付。

## 依据与边界

业务依据是原晨会、交接班的表单、动态模块、记录页面、设置页面及保存接口，不以其他业务应用为参照。不复制旧仓库源码、不依赖旧数据库或运行时。界面复用本平台 L2 组件，经公开 SDK 导出。

用户已明确：接班方一人填写确认；晨会先保存、随时本人登录签署；同一天可有多次记录。没有代签、补签、豁免、签署截止、签齐后才保存等流程。

填报工班由登录员工确定，前后端均不允许通过表单切换工班。普通工班负责人直接设置本工班。应用负责人跨工班管理与普通员工业务权限是不同问题，不能以“有配置权限”或平台管理员身份代替应用负责人身份。

## 验收方式

1. 每个模块同时核对字段、填写交互、保存目标、记录回显，不能用文本框替代业务。
2. 检查普通成员、工班负责人、应用负责人三种实际身份；不要求普通用户选择自己的工班。
3. L2 人员选择、日期时间、筛选、签名实际操作；拖拽需鼠标与触屏验收。
4. 录音验证开始/停止、选择文件、试听、保存、记录回放；自动草稿验证刷新恢复、账号隔离和保存后清理。
5. 测试通过和构建通过只能证明对应代码检查通过，不能宣称上述未完成业务已交付。
