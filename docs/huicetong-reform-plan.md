# 慧策通重构开发与验收计划

日期：2026-10-26。分支：`codex/huicetong-reform`。应用 2.0.0，平台 1.3.0。

本轮按用户确认的未投产场景直接重建慧策通，不做旧记录、旧附件和旧流程兼容；不处理其他应用数据。页面不展示额外的部门标签或说明段落，只保留必要操作、字段、年度提报提醒和错误信息。

## 确认范围

| 页面 | 交付 |
| --- | --- |
| 月度计划 | 自然语言整理及直接填写、单责任人、提交审核／驳回、审核后锁定、有效附件后责任人直接完成、延期申请与审批、表格和附件导出 |
| 督办提醒 | 上级任务派发、督办要求、办结标准、办理进度、时限、责任人、备注；有权维护删除、责任人直接完成 |
| 年度计划 | Excel 导入预览和人员修正、个人年度计划、完成按钮、按起止月份提示月度提报 |
| 语料库 | 顶部标签切换专有名词与标准示例；名词增删和解释维护、两列标准示例增删改；AI 保护名词并参考解释 |
| 基础配置 | 部门群 Webhook、提前／到期／逾期提醒规则、发送记录 |

附件仅保存和下载原件，按计划组织 ZIP；不解析正文、OCR、转码或有损压缩。单文件上限按用户选择定为 200 MiB。详情仅保留原件下载；列表点击多选后批量打包，外层按上海日期命名，内含“计划编号+责任人.zip”。

角色由应用管理员在平台现有角色功能配置；应用声明可组合的业务权限，不写死角色名。

录音转写到督办：依据 2026-10-26 追加需求，统一新增弹窗，交付浏览器录音、暂停续录、回听保存及手动填写；用户选择浏览器联网实时语音识别，逐条人工确认后派发。上传音频转写、AI 多任务提取、责任人识别、时限推断后续实现。

## 开发顺序

1. 重建数据模型、权限与状态流，删除分类、归口、整月送审／签发与完成复核。
2. 月度计划闭环，前置后端附件核验。
3. 语料库和 AI 保护；AI 整理后人工确认，不自动提交。
4. 独立督办和录音前端。
5. 年度 Excel 解析、责任人核对和月度提示。
6. 原件流式上传、视频格式和列表多选批量 ZIP。
7. V2 启停钩子管理定时扫描，通过平台 Webhook 网关推送。
8. 权限、数据、传输、页面及相关平台回归；构建、版本与文档。

## 验收重点

- 提报审核通过后员工不能改内容；驳回必须有理由，可重报。
- 只允许责任人办理；没有当前计划有效附件不能完成月度计划；完成无第二轮审核。
- 延期未批不改日期；批准后保存新旧时间及理由，并发操作受版本检查保护。
- 督办维护、删除与办理分别授权；年度计划按本人关系和数据范围展示。
- “2—5月”在 2、3、4、5 月提示，1 月和 6 月不提示；年度已完成后停止提示。
- 模型失败可手填；专有名词输出改写不能被静默接受。
- 原件字节不变；200 MiB 边界、大文件、重名、ZIP 层级、缺失文件和越权导出受检查。
- 无人访问页面时仍按北京时间提醒；应用启停、重复扫描、完成、改期和未知投递结果不导致盲目重发。
- 页面无部门标签、重复流程说明、业务模块或更多选项；在完整平台内验证桌面亮暗主题，窄屏不纳入本轮验收。

## 工程边界

平台新增后端附件元数据查询、部门工班查询、流式原件接收和受独立 export 授权的 ZIP 下载。沿用 V2 进程及启停钩子，不引入独立队列、第三套角色管理或旧应用运行机制。

ZIP 每批最多 100 条记录、1000 个附件、总包 2 GiB；无浏览器文件系统保存 API 时限制单包 256 MiB。年度导入最多 500 行，通过小批次写入并记录进度。

原排期参考为 15—23 人日，包含测试与修复、不含真实录音 AI。实际开发、验证结果与安装要求以[应用说明](../applications/huicetong/README.md)及交付验收记录为准。
