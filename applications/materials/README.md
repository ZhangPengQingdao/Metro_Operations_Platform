# 物料管理应用（试装版）

独立业务代码只依赖 `@metro/platform-sdk`。本目录没有旧 AFC 源码引用、平台内部导入或数据库连接；不迁移旧数据。

已实现业务服务、沙箱表单/列表、隔离 Node 后端入口及声明式迁移：

- 物料名称、型号（SKU）、单位；新建时可填初始数量，库存与入库流水在同一事务提交。
- 同组织 SKU 唯一；操作组织、操作人来自平台可信员工上下文，不接受 payload 覆盖。
- 首版数量为正整数，以物料单位计量，库存范围 0～2147483647；不接受小数或隐式四舍五入。
- 入库、出库使用库存版本比较更新，与流水插入组成同一事务。并发冲突交还调用者，不自动重放。
- 原流水不可修改或删除；冲销增加关联流水，冲销入库不能导致负库存；已冲销流水和冲销流水均不能再次冲销。唯一冲销标记和库存更新同事务写入。
- 库存和记录列表按可信员工组织过滤，支持分页；库存名称搜索、记录按物料筛选。
- 未知写入失败不自动重试。

`npm test` 运行规则测试。平台测试另以 PGlite 执行声明式迁移及 SQL 事务，验证流水失败回滚库存。这些测试不替代实际托管存储、Docker、浏览器或安装验收。

构建：`npm run build` 输出首版 dist；`node build.mjs --upgrade` 输出 dist-upgrade（保留追加的可空规格字段迁移）。使用独立 CLI validate/sign/verify/export-upload 导出 JSON 安装包，私钥不随应用分发。测试已覆盖签名、上传格式导入再验签及追加迁移兼容性。页面遇到未知写入停止继续写入并保留请求编号，不自动重试。

## 工班权限与设置

- 工班长：平台管理员分配工班长角色，并配置 `app.materials.read`、`app.materials.outbound`、`app.materials.manage`。只有工班长有应用侧边栏「设置」入口。
- 普通成员：分配检修工角色，配置 read/outbound；可以查询本工班库存/流水、出库，且只能修改本人出库记录。
- 物资管理员：工班长在「设置」查询在职本工班成员并任命/撤销；具有建档、入库和入库记录修改权限，不能进入设置或再次委任。原员工角色不变，仍需平台授予使用应用及 read/outbound 权限。
- 任命与撤销保留独立审计。设置采用 revision 比较避免覆盖他人修改。入库事务同时锁定并比较委任记录，撤销已提交后旧授权不能再写入库存。
- 工班长身份由宿主实时校验的权限决定，不依赖岗位名称、前端菜单、请求正文或应用存储自封身份。宿主在每次存储请求及提交前复核权限快照。
- 员工离职/停用/调离导致原工班身份不再有效；跨工班任命拒绝。

物料管理 0.2.7 要求平台至少 0.11.0。首屏使用一次 bootstrap 请求取得当前权限与列表，消耗记录用批量读取补全物料与冲销状态；旧平台没有按 ID 批量读取接口，不能安装此版本。生产资源域与受限存储管理账号仍须按部署文档验收，不能把本地结果视为生产上线证明。

## 界面与修改记录

库存列表提供新建物料、行内入库和出库；消耗记录展示流水，符合权限的记录行显示「修改」。设置仅对工班长显示。没有手动刷新按钮，进入页面、搜索、翻页、保存成功后自动读取列表。

修改不会覆盖原流水：同一事务更新库存、写入唯一冲销标记、关联冲销流水与新流水。重复修改旧记录、修改他人出库、导致负库存均拒绝。未知结果保留请求编号并阻止继续写入，不能自动重试。

前端通过公开 SDK 的 `@metro/platform-sdk/ui` 和 `@metro/platform-sdk/ui-styles` 使用平台同源 L2 组件，不导入平台源码。沙箱通过 JS 调用提交，保留禁止原生表单提交的隔离限制。

库存行的「修改」允许工班长和物资管理员修改名称、型号和单位；版本比较防止覆盖并发修改，不接受直接修改库存数量。出入库仍通过流水记录调整。

## 消耗记录与领用人

消耗记录页仅展示有效出库，移除类型列；通过「新增消耗」选择物料、数量和领用人。领用人使用本班组在职人员下拉框，表单不额外放置文本搜索框；后端按人员 ID 重新核对当前班组，记录保存人员 ID 与当时姓名。旧记录的领用人文本保留，修改时需重新选择。新增迁移 `migration-003.json` 为旧流水添加可空 `receiver_id`，不改写历史。

本人消耗记录提供修改和删除。删除弹窗显示返还数量，确认后在同一事务回补库存并追加关联冲销；原始记录不删除，重复删除拒绝，未知写入不重放。有效记录页隐藏已修改或删除的原记录，按原始游标分页；遇到全为历史记录的一页会提示继续下一页。

修改与删除图标使用 Phosphor 的 PencilSimpleLine、Trash，由公开 SDK UI 入口导出。

数量采用共享 L2 QuantityInput，可手动输入整数或用加减按钮调整。无本人记录操作权限时保留置灰按钮及原因提示。

工班长和已委任物资管理员可修改、删除本工班消耗；普通成员仅限本人。管理员修改保留原操作人归属，跨工班仍拒绝。沙箱通过宿主主题接口同步深浅色，本地文档首屏直接带当前主题。
