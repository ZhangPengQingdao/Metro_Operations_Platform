# 慧策通·计划督办

独立应用，当前版本 0.2.0，包含 [M2 编制闭环](../../docs/huicetong-app-plan.md#13-分期与里程碑)。采用员工业务授权、隔离后端、平台托管存储及标准沙箱页面，不依赖旧仓库。

## 已实现

- 按授权组织创建唯一的月度周期，维护三级分类字典。
- 编制和修改草稿条目，填写质量标准、时间、拟提报标记及至多 6 位责任人，并指定一位牵头人。
- 通过平台人员目录核验在岗责任人及所属组织；服务端按员工业务权限和组织范围复核读写。
- 平台宿主侧边栏提供“计划条目”和“分类字典”两个功能入口，分别对应 `/` 与 `/categories`；列表用 L2 筛选栏，组织、分类和人员用 L2 层级选择器。
- 周期、分类和条目写入附带审计事件；条目编辑使用版本比较，周期状态与条目写入在同一事务校验。未知写入结果不自动重放。

M2 新增归口绑定维护、条目提交与归口审核、周期送审/退回/签发/锁定、锁定后变更复审与负责人追认、汇总预览和 Excel 导出。周期签发暂采用**负责人应用内确认+审计**：平台 signatures 客户端已存在，但 L2 签字板交互未接入；须在组件就绪后改成服务端核验平台签字完成。周期退回通知暂仅记录待发审计事件，尚未接平台通知投递。

导出由服务端生成 xlsx 并记审计，沙箱通过 `downloadSandboxFile` 下载；宿主附件 SDK 的业务原件上传入口仅接受用户本地 `File`，尚无后端生成原件登记接口，因此没有附件登记/授权下载。清单声明 `ui.downloads: true`，服务端按读权限与组织校验后返回文件；受 Bridge 响应大小限制，单次 xlsx 不得超过 40 KB，大周期会明确报上限错误。页面从当前员工所在工班选择责任人及归口人；后端支持同部门跨工班，跨工班选择界面仍需补足。

规划书附录 A 只有分类树，没有提供 9 月 33 条原始电子表格；当前不能宣称与原表逐列人工核对完成。导入 TSV、督办、交账、归档属于后续里程碑，不在本版本内。

## 授权与构建

安装时为应用服务审批 `platform.app_data.read`、`platform.app_data.write`、`platform.people.read`；为员工授予应用内 `app.huicetong.read`，填报人授予 `fill`，归口人授予 `review` 并在二级分类上绑定，计划管理岗授予 `manage` **及** `fill`、`review`（平台逐接口仅支持单项权限码，管理岗要代管填报/复审须同时授予对应权限），部门负责人授予独立的 `sign`。各项部门级权限限定在实际计划组织；不以普通员工身份替代负责人身份。安装、审批及授权按 [应用接入](../../docs/applications.md) 进行。

```sh
npm run build:sdk
npm --prefix applications/huicetong test
npm --prefix applications/huicetong run build
node packages/platform-cli/dist/cli.mjs validate applications/huicetong/dist
```

构建产物在 `dist/`，由 `build.mjs` 生成清单、前后端包和初始迁移。安装前应使用正式发布者私钥签名并在管理端完成审批；本源码不含私钥或生产数据。
