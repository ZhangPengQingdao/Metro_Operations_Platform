# 慧策通·计划督办 2.4.0

月度计划、上级督办、年度计划、AI 语料库和部门群提醒。运行于平台 1.7.0 及以上（低于2.0.0），构建为单个 `.mopkg`。

语料现在由平台知识服务保存与检索，应用声明 `terms` 和 `examples` 两个库。提报者可以检索所属组织语料；维护者可以查看完整库与编辑。计划字段、名词保护和人工提交继续由慧策通处理。

本次按“尚无有效旧语料”直接切换，不迁移旧语料，保留2.0模型的历史语料迁移和表。先升级平台并运行 `db:init`，再安装2.4.0应用包；已有有效语料的其他环境不能直接套用此切换方式。1.x旧流程安装与2.x模型不兼容，具体限制见下文。

## 页面和流程

| 页面 | 行为 |
| --- | --- |
| 月度计划 | 自然语言整理或直接填写，单一责任人；提交审核，通过后执行，驳回后修改重报；责任人上传附件后直接完成 |
| 督办提醒 | 独立派发上级任务，维护督办要求、办结标准、办理进度、时限、责任人和备注；责任人直接完成 |
| 年度计划 | 统一新增入口，上传 Excel 导入或手动新增；列映射、人员核对、导入预览；员工查看本人计划，点击完成；执行月份指导月度提报 |
| 语料库 | 顶部标签切换专有名词和计划标准示例；名词解释可维护，示例增删改；AI 整理保护名词并参考解释 |
| 基础配置 | 每部门一个企业微信群机器人 Webhook，设置提前提醒天数、发送整点和逾期提醒间隔，查看发送记录 |

页面不展示部门标签、顶部年月文字和流程说明。月份／年度通过筛选修改；编号在列表中独立成列，内容与完成标准最多显示两行，详情保留全文。月度列表默认无复选框，点击工具栏左侧的幽灵按钮“多选”后可勾选本页或全选筛选结果，再下载附件压缩包。退出多选清空选择。年度计划提示仅在月度提报弹窗出现。

新计划按业务类型生成简短编号：月001、年001、督001。计数与记录在同一事务内写入，编辑不改号，删除不复用。`002-corpus-and-numbers.json` 为现有 2.0 模型追加名词解释字段和编号计数表，不修改已应用的初始迁移。

月度计划状态：`draft → submitted → in_progress → completed`；审核驳回为 `returned`，可修改重报。待审核及已通过内容不可由员工修改。完成不再审核，服务端核验责任人和当前记录的有效附件。逾期如实记录完成时间；修改承诺期限须申请延期，填写理由，经延期审批权限人员批准后生效。

督办、年度计划创建后为 `in_progress`，责任人点击完成直接进入 `completed`，不强制附件。年度月份包含起止两端：2—5 月在 2、3、4、5 月提示；已完成年度计划不再提示，月度计划完成不自动关闭年度计划。

## 授权

由应用负责人使用平台现有应用角色管理创建角色，不根据角色名称或平台管理员身份判断业务权限。

| 权限 | 用途 |
| --- | --- |
| `read`、`fill` | 查看月度计划；提报、保存或修改本人的草稿／驳回记录 |
| `review` | 审核月度提报，通过或填写理由驳回 |
| `complete`、`extend` | 责任人办理月度计划；申请延期 |
| `extension_review` | 审批部门延期申请 |
| `export`、`attachment_export` | 月度表导出按钮；受服务端独立校验的附件打包导出 |
| `supervision_read`、`supervision_manage`、`supervision_delete`、`supervision_complete` | 查看、派发维护、删除和责任人办理督办 |
| `annual_read`、`annual_manage`、`annual_complete` | 查看、导入维护和责任人完成年度计划 |
| `corpus`、`settings` | 分别进入语料维护、群提醒配置，支持部门／指定组织／全部范围 |

普通员工建议授予三个业务域的查看和本人办理权限，以及 `fill`、`extend`，数据范围取本人。提报审核、延期审批和维护权限按岗位配置部门范围。管理人员具有办理权限也不能替其他责任人点击完成。

语料库和设置页分别由 `corpus`、`settings` 控制；业务数据仍逐次检查组织范围、创建人或责任人。附件回调是受应用业务授权保护的入口，按具体记录校验对应业务域权限，不要求督办用户额外具备月度查看权限。

## 附件

保存原件，不解析 Word／Excel／PDF 正文，不 OCR，不转码或有损压缩。

- 支持 `.doc .docx .xls .xlsx .pdf .zip .rar .7z .gz .jpg .jpeg .png .gif .webp .bmp .mp4 .m4v .mov .webm .mkv .avi`。
- 每文件最多 **200 MiB**，每记录最多 500 份；上传与平台存储采用有界流式处理。
- 原件通过平台授权接口上传、查询和下载；后台完成核验通过公开 `platform.attachments.list` 查询，不相信页面传入的附件数量。
- 详情仅提供单份原件下载；批量打包入口位于月度列表的“多选”模式，可跨页勾选或全选筛选结果（最多 100 条）。外层为上海日期 `YYYY-MM-DD.zip`，内层为 `计划编号+责任人.zip`。
- 每批最多 100 条记录、1000 份文件，总包不超过 2 GiB；中文、重名和路径字符按规则处理，不解压员工上传的压缩包。
- 支持文件系统保存 API 的浏览器直接流式落盘；其他浏览器使用有界 Blob 下载，单包最多 256 MiB，超限应拆批或使用支持的浏览器。
- 文件缺失、读取失败或授权变化不会作为成功的完整包返回。

上传结果未知时按原 `intentId` 查询核对，不自动重传；业务写入附带 `requestId` 和版本校验，未知结果不自动重放。

## 年度 Excel 与 AI

点击“新增年度计划”打开紧凑上传弹窗；年度与模板下载并列，选择文件后显示列映射，底部统一“解析并预览”，预览阶段扩大弹窗。可选择或拖入 Excel，也可点击“手动新增”进入表单。新增和导入均继承当前筛选年度。从弹窗下载导入模板，至少包含工作计划内容、执行月份、责任人。选择工作表并映射列，时间支持单月、2—5 月、全年和 Excel 日期值。选择年度后解析，在预览中修正月份、内容和责任人，再确认分批写入（最多 500 行，源文件最多 5 MiB）。重名及无法识别的人员不会自动分派，可切换工班后搜索确认。导入完成计数持久化，重复请求不会重复写入。

语料库顶部标签在专有名词与计划标准示例之间切换，保留各自搜索条件。专有名词可新增、删除和维护解释（最多 500 字）；已创建的名词名称固定，改名请删除后重新新增。AI 通过平台模型网关整理，参考命中名词的解释和相关标准示例；解释作为参考数据，不执行其中指令。命中的专有名词必须逐字出现在输出计划内容；输出不合格时提示修正，不静默接受改写。AI 整理只生成一条待确认建议，不直接提报。模型失败可直接填写。

语料库的搜索与新增位于顶部标签栏右侧，两个标签分别保留各自搜索条件。

## 群提醒与录音入口

在基础配置保存企业微信群机器人地址，仅允许官方企业微信机器人 HTTPS 地址。普通 API 不返回完整 Webhook，操作记录不保存 URL。

应用 V2 `start/stop` 钩子管理每分钟扫描，按北京时间在指定整点后检查提前到期、当天到期和逾期事项；无人打开页面时仍运行。应用停用、平台停机期间不发送，恢复后按当日条件扫描。提醒领取与发送结果持久化，重复扫描不重复发送；超时或结果未知不自动重发。

督办列表统一为“新增督办”入口。弹窗内可开始录音、暂停／继续、结束、回听并保存录音，也可选择本机音频回听，或直接“手动填写”。录音最长 20 分钟、约 50 MiB 到限停止；音频文件上限 50 MiB，支持 MP3／WAV／M4A／MP4／WebM／OGG／AAC。录音只留在当前弹窗，关闭前可保存到本机；关闭或切换页面会释放麦克风与识别会话。

按用户选择接入浏览器 `SpeechRecognition`／`webkitSpeechRecognition` 中文实时转写：点击开始录音后才请求麦克风，启用“实时转写”时由浏览器的联网识别服务处理语音。此能力依赖浏览器支持、麦克风权限及服务网络；未支持、无语音或网络错误会显示原因，原录音和已识别文字仍可保留并手动编辑。暂停与续录之间保留已确认文字，临时识别内容单独显示。识别停止后超时会释放文本编辑，不让服务异常阻断手工填写。

实时识别只针对现场录音，不把上传音频宣称为已转写。录音与转写文本须由用户整理确认：每条督办要求最多 500 字，超长不截断，核对责任人、办结标准和时限后才通过原有权限与业务接口派发。AI 多任务提取、责任人识别和时限推断未接入。录音需要 HTTPS 或本机地址。

## 平台统一对话（2.2.0）

接入平台统一对话，支持月份追问、平台知识检索与计划草稿，实际提报仍在应用中完成。 需要平台 1.5.0 或以上。能力和提示卡片声明于 `app.json` 的 `agents`。

## 2.3.0 只读工具

计划编排通过统一只读工具检索当前部门专有名词及示例；业务页面继续自行选择授权部门。 最低平台版本为 1.6.0。升级后需授予应用 `platform.tools.read` 服务权限；不自动扩大员工业务权限。接入契约见[工具指南](../../docs/developer/tools.md)。

## 2.4.0 逐条语料语义检索

要求平台≥1.7.0。在原有语料库逐条添加、编辑标准示例；后台自动建立索引，列表显示进度和失败状态，可手动重建。管理端独立配置向量模型。模型未配置或库内索引不完整时使用文本检索并明确标注。计划整理和统一对话展示本次检索条目 ID 与版本，专有名词仍按原文精确匹配。无需先上传文档。
