# 慧策通更新日志

## 2.4.0

- 标准示例接入平台语义索引，展示状态并支持手动重建。
- 计划整理及统一对话展示检索方式、参考条目 ID 和版本；专有名词仍精确匹配。
- 要求平台≥1.7.0，继续逐条维护语料，不要求上传文档。

## 2.3.0

- 计划编排通过统一只读工具检索当前部门专有名词及示例；业务页面继续自行选择授权部门。
- 要求平台 1.6.0，增加 tools.read 平台授权。

## 2.2.0

- 接入平台统一对话，支持月份追问、平台知识检索与计划草稿，实际提报仍在应用中完成。

## 2.1.0 — 2026-10-27

- 专有名词和标准示例改用平台知识库，列表、维护与计划检索通过公共 SDK 完成。
- 保留名词保护、解释、质量标准和人工提报；零相关示例不再进入模型上下文。
- 要求平台1.4.0；本次无有效旧语料，直接切换，旧表不自动迁移或删除。

## 2.0.0 — 2026-10-26

- 重建月度计划、督办提醒、年度计划、语料库、基础配置五页，删除分类、归口、签发和完成复核。
- 单责任人、逐条提报审核、审核后锁定；责任人上传有效附件后直接完成，延期须理由及审批。
- 年度 Excel 预览、人员修正、分批导入、起止月份提醒；专有名词保护及标准示例辅助 AI 整理。
- 原件支持图片、视频等格式，单文件 200 MiB；详情下载单份原件，列表多选后按日期批量 ZIP 导出。
- 部门群 Webhook、定时到期提醒及发送记录；督办统一新增弹窗，支持浏览器录音、暂停续录、回听保存、中文实时语音识别和手动确认派发。
- 角色通过平台现有功能自由组合；页面去掉额外部门标签和说明段落。
- 月份／年度进入共享筛选，取消筛选保留原值；列表统一复选框、选择反馈、状态及空态，详情补齐加载失败重试和附件要求。
- 新增与导入继承当前年度，导入解析后收起列映射；责任人工班切换清空旧选择，语料两张列表独立搜索，表单按必填与日期范围校验。
- 跟随平台明暗主题，取消独立侧栏主题入口；修复真实平台工作台摘要读取失败，按桌面平台集成流程验收。
- 语料库搜索与新增操作移至顶部标签栏右侧，取消独立工具行，切换标签保留各自搜索条件。
- 前端打磨：多选改为列表左侧幽灵按钮，编号独立成列，内容与标准两行省略；移除详情附件与办理记录的多余分隔线。年度导入精简首屏布局，统一底部预览和导入操作。
- 界面复核：年度新增合并上传导入与手动新增；语料顶部标签切换，新增可维护的名词解释并接入 AI 参考。列表默认隐藏复选框和年月文字，多选模式支持跨页全选与批量附件下载；计划编号改为月001、年001、督001，事务计数防止并发重号。
- 未投产版本直接采用新安装数据模型，不提供旧数据、附件和旧流程兼容。

## 0.4.0 — 2026-10-10

- 增加只读工作台摘要：按现有 read 授权范围统计全部月份计划，排除取消记录，提供完成情况、每日新增趋势和最新记录；通过公开 SDK 获取有范围的计数与字段投影。

- 新增一句话整理标准计划，整理后进入确认页，保留原话与缺失信息提示；模型不可用可手工填写。
- 提报采用两步界面，责任人搜索选择；列表聚焦计划、期限、牵头人和状态，跟进材料与动态平铺展示，备注和详情按需展开。
- 新增逐次进度履历、照片及文档证明材料，不再以进度覆盖原计划备注。
- 完成提报先进入待办结，由归口人或目标组织管理人员确认，支持填写意见退回重报；旧客户端不能直接置为已完成。
- 办结、进度和照片关联使用版本与周期状态事务守卫，附件按源计划授权，结果未知不自动重放。
- 追加第三份迁移，新增 AI 和附件服务权限；平台最低版本沿用同工作区看板接入的 0.25.0。
